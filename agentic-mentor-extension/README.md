# Agentic Mentor VS Code Extension
## How to Run:


To run the Agentic Mentor VS Code extension:

1. Open the VS Code extension root folder `agentic-mentor-extension` in VS Code
```bash
cd agentic-mentor-extension
code agentic-mentor-extension
```
2. Press `F5` to open a new VS Code window with the extension enabled (The extension will be available as a webview panel).
